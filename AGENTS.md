# AI Coding Agent Instructions

## Working rules

1. Inspect the repository before changing it.
2. Explain the intended change before implementation.
3. Identify affected files.
4. Make the smallest useful change.
5. Run tests after changes.
6. Report failures honestly and diagnose them.
7. Update documentation when architecture or behavior changes.
8. Prefer incremental commits with meaningful messages.
9. Do not introduce frameworks or infrastructure without a demonstrated need.
10. Never commit secrets, API keys, passwords, or tokens.

## Learning rule

The purpose of this repository is both building and learning. For every important implementation, explain:

- why it exists
- what problem it solves
- alternatives
- tradeoffs
- failure modes
- testing
- evaluation
- production implications

## Current phase

Phase 0 — Foundation. Do not jump ahead to RAG or agent frameworks until the current foundation is understood and tested.
